## Conclusion limitations
The study is limited to five sugarcane varieties and the evaluated collection conditions. Source-image-grouped cross-validation reduces leakage between derivatives of the same image, but unavailable plant identifiers prevent establishing independent-plant generalization. External validation across farms, seasons and devices, matched component ablations, and end-to-end deployment measurements remain necessary. Missing experimental configuration and historical model artifacts limit exact computational reproduction.

## Data and code availability — current transparent status
Sugarcane-PK v1.0 is archived on Zenodo (https://doi.org/10.5281/zenodo.18619387) under CC BY 4.0, as stated in the dataset record. The accompanying package preserves the supplied baseline MATLAB code and provides newly developed MATLAB and Python reference implementations. The exact historical experimental subset, original checkpoints and implementation configuration remain unavailable for independent reproduction. The reference implementations have not independently reproduced the reported historical scores.
